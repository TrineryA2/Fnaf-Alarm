# FNAF 6:00 AM Alarm

A Five Nights at Freddy's inspired alarm clock with dramatic flip animations, multiple alarms, and complete visual customization.

## Features

- **Flip Animation** - Minutes flip first, hours flip after with a smooth 3-second animation
- **Multiple Alarms** - Set unlimited alarms with individual ON/OFF toggles
- **CSS Editor** - Live custom CSS editor to change colors, fonts, and themes
- **Display Modes** - Choose between Hour-Only or Hour+Minute display
- **Custom Tones** - Upload your own MP3, WAV, or OGG alarm sounds
- **Persistent Storage** - All settings saved locally
- **Touch Friendly** - Swipe from left edge to open settings
- **Fully Offline** - No internet connection required

## How to Use

1. Open the app
2. Swipe from left edge to open settings
3. Add alarms, change colors, upload custom tones
4. Click "TEST HOUR CHANGE" to preview the flip animation
